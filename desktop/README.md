# Memora 데스크톱 앱

비서가 창 하나로 늘 곁에 있게 만드는 앱입니다. 윈도·맥·리눅스에서 돕니다.

서버는 **memo-ora.com** 으로 고정입니다. 설정으로도 바꾸지 않습니다.

## 받는 곳

Memora 웹의 [다운로드 센터](https://memo-ora.com/app/downloads)

| 운영체제 | 파일 |
|---|---|
| 윈도 | `Memora_windows_<버전>.exe` (설치 마법사) |
| 맥 | `Memora_macos_universal_<버전>.dmg` (Apple 칩·Intel 한 파일) |
| 리눅스 | `Memora_linux_<버전>.deb` (Ubuntu·Debian 설치 꾸러미) |

저장소가 비공개라 사람은 **Memora 웹의 [다운로드 센터]**에서 받습니다. 태그를 밀면 CI 가 굽고 공개한 뒤
다운로드 센터에 알려, 몇 분 안에 거기 올라옵니다(plan/64).

서명하지 않았습니다. 윈도는 처음 열 때 [추가 정보] → [실행], 맥은 오른쪽 클릭 후
[열기] 를 한 번 하면 그다음부터는 묻지 않습니다.

## 이 앱이 무엇인가

**쓰기 위한 앱입니다** (plan/62). VS Code 처럼 왼쪽에 아이콘 막대가 있고, 거기 선 문은 셋뿐입니다.

- **비서와 대화 · 소식 · 커뮤니티.** 세 문의 안쪽은 memo-ora.com 이 "앱 모드" 로 그립니다. 사진·마크다운·
  도구 카드·첨부가 웹과 똑같습니다. 문마다 뷰가 하나씩 살아 있어서 오가도 스크롤과 쓰던 글이 그대로입니다.
- **나머지는 웹에서.** 비서 관리, 내 정보, 스케줄, 지식 같은 자리로 가는 링크는 브라우저가 엽니다.
  앱은 쓰는 곳이고, 설정하는 곳은 웹입니다.

앱만 하는 것:

- **빠른 대화.** 어디서든 `Ctrl(⌘)+Shift+Space` 로 입력칸이 뜹니다. 비서에게 한 마디 묻고 그 자리에서
  답을 읽습니다. 말로 물을 수도, 답을 소리로 들을 수도 있습니다. 말은 그 비서의 가장 최근 대화에 쌓이고,
  [대화에서 이어 보기] 로 본창의 그 대화로 갑니다.
- **아바타.** 비서의 얼굴이 떠 있는 작은 창입니다. 숨을 쉬고, 말할 때 소리에 반응하고, 거기서 바로 말을
  걸 수 있습니다. 비서가 먼저 말을 걸면 아바타가 말하고 [답하기] 가 붙습니다. 접으면 얼굴만 남고, 옮겨 둔
  자리와 모양은 다음에도 그대로입니다.
- **알림.** 비서가 먼저 건넨 말, 인박스, 메시지를 그 순간 알립니다(서버의 실시간 흐름을 듣습니다).
  아이콘 막대의 종에서 최근 알림을 훑고, 누르면 그것이 있는 곳으로 갑니다.
- **트레이와 단축키.** 창을 닫아도 앱은 남습니다. 단축키(빠른 대화·아바타·본창)는 설정에서 바꿀 수 있고,
  다른 프로그램이 쓰는 조합이면 그렇다고 알려 줍니다.
- **설정.** 컴퓨터를 켜면 시작, 시작할 때 아바타, 테마, 곁에 둘 비서, 답을 소리로, 알림 종류, 단축키.

로그인과 로그아웃은 웹이 합니다. 갱신 쿠키를 쥔 쪽은 웹 하나이고, 앱은 웹이 얻은 토큰을 받아 쓰기만 합니다
(plan/46 §2).

리눅스에서는 XWayland(X11)로 뜹니다. 웨이랜드에서는 아바타와 빠른 대화가 제자리에 뜰 수도, 항상 위에 있을
수도 없어서입니다. `MEMORA_OZONE=wayland` 로 끌 수 있습니다.

## 만드는 법

```bash
cd desktop
npm ci
npm run dev        # 띄워 보기
npm run typecheck  # 타입
npm test           # 계약 테스트
npm run dist       # 이 운영체제용 설치본
```

`npm run dist:win` · `dist:mac` · `dist:linux` 로 하나만 구울 수도 있습니다.
맥 설치본은 맥에서만, 윈도 설치본은 윈도에서만 만들 수 있습니다.

## 내보내는 법

`desktop-v0.6.0` 처럼 태그를 밀면 GitHub Actions 가 세 운영체제에서 동시에 굽고
한 릴리스에 붙입니다. 세 개가 다 들어온 뒤에야 릴리스가 보입니다.

```bash
git tag desktop-v0.6.0 && git push origin desktop-v0.6.0
```

## 구조

```
src/
  shared/contract.ts   메인과 앱의 창들이 주고받는 것, 문의 규칙(웹 lib/desktop.ts 와 같다)
  main/
    index.ts           수명, 로그인 상태에 따른 틀
    window.ts          본창: 틀(앱 화면) + 세 문의 웹 뷰, 문 밖 링크는 브라우저로
    controller.ts      계정·비서, 아바타, 빠른 대화, 알림, 트레이, 테마, 단축키를 잇는다
    state.ts           틀이 그리는 것의 원본 하나
    live.ts            실시간 알림 흐름(/api/notifications/stream)
    chat.ts            비서에게 묻기(빠른 대화·아바타 공용), 받아쓰기·목소리
    stream.ts          턴 SSE. 메인에서 돌아서 창을 닫아도 안 끊긴다, 멈추면 이어 붙는다
    alerts.ts          인박스 제목과 누르면 갈 곳
    quick-window.ts    빠른 대화 창
    avatar-window.ts   투명·항상 위 아바타 창
    settings.ts        userData/settings.json
    shortcuts.ts       전역 단축키, 못 잡은 것 알리기
    auth.ts            웹이 준 토큰을 받아 든다. 앱은 갱신하지 않는다
    api.ts             서버로 나가는 요청이 지나는 한 군데
    ipc.ts             앱의 창들이 부를 수 있는 것의 전부
  preload/
    host.ts            세 문의 웹 뷰에 얹는 다리(토큰은 받기만, 문 이름·테마·이동 요청)
    index.ts           앱의 창 셋(틀·아바타·빠른 대화)의 다리
  renderer/            shell.html(틀) · quick.html(빠른 대화) · avatar.html(아바타)
```
