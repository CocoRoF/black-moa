# plan/77 — 파일은 계정의 것, 비서는 거기에 잇는다

## 0. 지시 (2026-09-30)

> [내 정보] 섹션은 정보를 모으는 공간이고, [파일]에 모든 정보를 모은 뒤 비서를 해당 [파일]에 연결한다.
> [다양한 데이터 소스] → [내 정보의 요소: 스케줄·파일 …] → [비서]와 연결.

Drive 가져오기가 "넣을 비서" 를 묻고 있었다 — 파일이 비서 한 명에 묶인 옛 구조 탓이다(스케줄·메일·인맥은 이미 [내 정보]
원천이었는데 파일만 비서의 것이었다).

## 1. 바뀐 것

| | 전 | 후 |
|---|---|---|
| 파일의 주인 | 비서(agent_id 필수) | 계정. agent_id 는 "들어온 비서"일 뿐, 비울 수 있다(0083) |
| 같은 바이트 | 같은 비서 안에서 하나 | 주인이 준 파일은 계정 안에서 하나 |
| 나와의 대화 | 그 비서가 받은 파일만 | 어느 비서든 내 파일 전부 + 그 비서가 방문자에게 받은 파일 |
| 외부인과의 대화 | 그 비서가 받은 파일 중 [지식] 탭에서 고른 것 | 내 파일 무엇이든 [지식] 탭에서 이은 것 |
| Drive 가져오기 | 비서를 고르는 창 → 그 비서의 파일 | 바로 파일 선택 창 → [내 정보 → 파일] |
| 비서를 지우면 | 받은 파일도 지움 | 주인이 준 파일은 남고 비서 칸만 빈다(방문자가 준 파일은 지운다) |
| 저장 공간 | 비서별 칸 | 비서별 칸 + [내 파일] 칸 |

방문자가 준 파일은 그대로 그 비서·그 방문자 대화에 딸린다(남이 쓴 글이라 저절로 퍼지지 않는다).

## 2. 대화상자 안 드롭다운 위치

셀렉터 목록은 `position: fixed` 로 화면 기준에 놓인다. 대화상자의 등장 애니메이션(`fade-up`·`sheet-up`)이 `both` 라 끝난 뒤에도
`transform: matrix(1,0,0,1,0,0)` 를 붙들어, 그 안의 fixed 가 대화상자를 기준으로 놓였다(운영 탐침: 조상 하나가 transform 을 가짐).
등장 애니메이션을 `backwards` 로 — 끝나면 변형을 놓는다.
