# plan/72 — 공개 대화의 두 번째 모양: 무대

> 커밋 제목은 `plan/71: …` 로 나갔다(같은 날 다른 작업이 71 을 먼저 썼다). 이 문서가 그 작업이다.

## 0. 요청 (2026-09-29)

- [비서] 공개 채팅방에 모양 두 가지. 지금의 채팅(기본)과, 게임 같은 모양.
- 게임 같은 모양: `images/background.png` 를 배경으로, 비서의 프로필 그림을 **그대로** 가운데에 세운다(얼굴부터 상체까지
  자연스럽게). 게임 같은 대화창으로 말을 걸고, 전체 기록을 보는 자리도 있다.
- 배포(링크)할 때 사용자가 정한다. 기본은 채팅. 정할 때 PC 와 휴대폰에서 어떻게 보이는지 미리 볼 수 있어야 한다.

## 1. 설정

- 링크마다 `settings.layout`: `chat`(기본) | `stage`. `services/agents.py` 의 `LINK_LAYOUTS`·`link_layout()` 이 읽는 곳
  하나다(모르는 값은 chat).
- 만들 때(`LinkCreate.layout`)와 고칠 때(`PATCH /api/links/{id}` 의 `settings.layout`) 정한다. 링크 정보
  (`_link_settings_out`)와 공개 링크 정보(`/api/public/links/{code}` 의 `link.layout`)에 실린다. 공개 정보에는 세울 그림
  `agent.character_url`(올린 원본)도 실린다. 없으면 프로필 사진(`avatar_url`)을 세운다.
- 화면: 링크 카드의 [화면 모양](그림 카드 둘, 누르면 바로 저장) + [미리보기], 새 링크 창에도 같은 고르기.

## 2. 무대 (`components/public/StageView.tsx`)

- **배경**: 사무실(`public/stage/office.webp` 1672px, 좁은 화면은 `office-960.webp`, 옛 브라우저는 `office.jpg`). 아래를
  살짝 어둡게 해 사람과 대화창이 뜬다.
- **비서**: `lib/figure.ts`. PC 앱의 아바타(plan/63)와 같은 방법이다. 투명 PNG 는 그대로 쓴다. 흰(밝은 무채색) 바탕은
  가장자리에서 이어진 곳만 걷는다(아래 가장자리는 시작점이 아니다, 흰 셔츠). 걷을 수 없는 사진은 둥근 카드로 세운다.
  사람이 차지한 사각형을 재서 머리가 위 여백(7%, 휴대폰 10%)에 오게 한다. 세로로 긴 그림(전신)은 머리부터 허리까지만
  보이게 키운다. 잘린 아래 끝은 대화창 뒤에 숨긴다. 숨 쉬듯 아주 조금 움직이고, 말하는 동안 비서 색으로 은은하게 빛난다.
- **대화창**(비주얼 노벨식): 비서 색 이름표, 역할 한 줄, 내가 한 말(작게), 지금 하는 말은 한 글자씩(누르면 끝까지, 밀리면
  빨라짐), 카드·멈춤·오류 표시, 처음 물어볼 것, 입력칸 + 음성 입력 + [말걸기]/[중지]. 미리보기·쉬는 중·내 비서 표시는
  이름표 줄 오른쪽에 둔다(얼굴 위에 두면 머리를 가렸다).
- **대화 기록**: 채팅과 같은 `MessageList`. 넓은 화면(1000px 이상)은 옆에 420px 로 붙어 무대를 좁힌다. 비서와 대화창은
  남은 자리의 가운데로 간다. 좁으면 무대를 덮는다. 모양(휴대폰/PC)은 전체 폭으로 정한다. 기록이 붙어 무대가 좁아져도
  휴대폰 모양으로 바뀌지 않는다.
- 크기는 창이 아니라 **무대 자신의 크기**로 잰다(ResizeObserver). 그래서 미리보기의 작은 틀 안에서도 휴대폰 모양이
  휴대폰 모양으로 나온다.
- 말·카드·중지·음성·실시간 동기화는 채팅과 같은 길(`PublicChat` 의 runner)이다. 모양만 다르다.

## 3. 미리보기 (`components/agent/LinkLayout.tsx`)

- 그 링크의 실제 공개 화면을 `?preview=chat|stage` 로 틀(iframe)에 띄운다. PC 1280×800, 휴대폰 390×844 를 줄여서
  보여 준다. 넓으면 나란히(높이 맞춤), 좁으면 위아래로. 틀 안에서 채팅/무대를 바꿔 볼 수 있다(저장하지 않음).
- `?preview=` 는 방문자 세션·환영 관문·Turnstile 을 건너뛰고 예시 대화(인사말, 물음 하나, 답 하나)를 보여 준다.
  말은 걸 수 없다. 예시 대화에는 시각을 두지 않는다. 서버가 그린 시각과 브라우저의 시각이 달라 화면이 어긋났다(React #418).
- nginx CSP `frame-src` 에 `'self'` 를 넣었다(콘솔이 자기 사이트의 틀을 막고 있었다). 남이 콘솔을 틀에 넣는 것
  (`frame-ancestors 'self'`)과 공개 화면의 `frame-ancestors *` 는 그대로다.
- nginx 설정은 파일 하나를 bind 로 붙여 둔다. `git pull` 뒤 `nginx -s reload` 로는 옛 파일을 읽는다.
  **`docker compose restart nginx`** 를 해야 한다.

## 4. 함께 고친 것

- **색 토큰을 `@theme inline` 으로.** 그냥 `@theme` 은 `--color-bg: var(--bg)` 를 `:root` 에서 한 번 풀어 버린다. 그래서
  안쪽의 `.dark`(무대)나 `--accent` 덮어쓰기가 `bg-*`·`text-*` 에 닿지 않았다(기록 창이 무대 안에서 밝게 떴다).
  그 결과:
  - 무대의 기록 창이 어둡다.
  - 공개 대화의 버튼과 내 말풍선이 비서 색을 따른다.
  - 주인 대화 화면(내 말풍선, 고른 대화)도 비서 테마 색을 따른다. 원래 코드가 의도한 대로다.
- 주인 대화의 `--accent: var(--accent)` 자기 참조를 고쳤다(테마 색이 없으면 색이 비었을 것). 이제 테마 색이 있을 때만
  덮고, 글자색(`--accent-fg`)도 함께 정한다.
- 링크 카드 통계에서 대화 수와 주고받은 말 수가 둘 다 "대화" 였다. 뒤의 것을 "주고받은 말" 로 바꿨다.

## 6. 남은 것

- 제니의 그림은 원래 사진에 머리카락 둘레의 청록색 테와 체크무늬 바탕이 박혀 있다(JPEG, 투명 아님). 바탕은 걷히지만
  청록 테는 그림의 일부라 남는다. 투명 PNG 를 올리면 깨끗하다.
- 배경은 기본 사무실 하나다. 배경 고르기·올리기는 나중에 붙일 수 있다(`BACKGROUND` 한 곳).

## 7. 다듬기 (2026-09-29 오후) — 비서가 너무 크다, 위 단추가 붙어 있다

- **고른 얼굴은 전신으로 선다.** 프리셋 얼굴은 동그라미용으로 512 에 자른 상반신이다. 무대가 그것을 세우면 얼굴만
  화면 가득 부풀었다(머리 약 400px). 흰 셔츠도 바탕과 함께 걷혀 구멍이 났다. 프리셋 15개마다 투명 전신 그림을 두고
  (`frontend/public/presets/<이름>-full.webp`, 75~185KB, 원본을 여백만 잘라 세로 1400), 공개 정보의 `character_url` 을
  `AG.stage_figure` 로 준다: 올린 원본 > 고른 얼굴의 전신 > 없음. 주인 쪽 `character_url` 은 저장값 그대로라서
  PC 앱의 아바타 모양은 바뀌지 않는다. 프리셋을 더하면 `PRESET_FIGURES` 에 이름을 넣고 파일도 넣는다(테스트가 확인한다).
- **placeFigure 를 작게.** 보일 만큼은 그림 모양으로 정한다: 전신은 위 55%(머리~엉덩이), 무릎 위까지인 그림은 75%,
  상반신은 전부. 머리는 무대 높이의 15%(휴대폰 14%)를 넘지 않는다. 폭은 PC 60%, 휴대폰 115% 까지다.
  1920×910 에서 머리가 약 400px → 130px 가 됐다.
- **위 단추.** `safe-pt` 유틸리티가 `p-3` 의 위 여백을 0 으로 덮어서 단추가 화면 끝에 붙어 있었다. 이제 여백을 따로 준다
  (PC 위 18·옆 24px, 휴대폰 12px). 비서 표, [대화 기록], [더보기] 는 같은 44px 둥근 유리 단추로, 사이는 10px 다. 뒤에 옅은
  그늘을 깐다. [더보기] 단추는 무대가 그리고(`menuItems`), 차림표는 body 로 나가므로 `menuClassName="dark"` 를 준다.
- 확인: 임시 비서(끝나고 지움)로 남자, 여자, 도트, 앉은 그림 넷을 PC 1920×910 과 휴대폰에서 찍어 봤다. [더보기] 차림표는
  여섯 항목이 어둡게 뜬다.
- **[대화 기록] 은 옆 창으로.** 넓은 화면에서 옆에 붙어 무대를 좁히던 것(§2)을 그만뒀다(사용자 요청). 이제 모든 폭에서 무대가
  어두워지고(`bg-black/60`), 기록이 오른쪽에서 밀려 나온다(PC 420px, 휴대폰 화면 가득). 무대의 자리는 그대로라 비서와
  대화창이 움직이지 않는다. 어두운 곳을 누르거나 Esc 로 닫는다.
