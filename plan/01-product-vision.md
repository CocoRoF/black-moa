# 01 · 제품 비전

## 슬로건

**"당신의 진짜 비서를 만들어보세요."**

내 정보를 알고, 내 인맥을 알고, 내 메일·일정을 보는 비서. 나 대신 사람들을 응대한다.

## 세 종류의 사람

| 역할 | 누구 | 하는 일 |
|---|---|---|
| **관리자(Admin)** | 서비스를 최초로 띄운 사람(최초 가입자) | 인프라·프로바이더 키·모델 카탈로그·요금표·플랜·가입 정책·사용자 관리 |
| **오너(Owner / User)** | 가입한 일반 사용자 | 비서 에이전트 생성, 페르소나·프롬프트 설정, 내 정보/지식/인맥 주입, 계정 연동, 공개 링크 발급, 인박스 확인, 크레딧 충전 |
| **방문자(Visitor)** | 공개 링크로 들어온 외부인 (비회원) | 오너의 비서와 대화, 메시지 남기기, 미팅 요청, 파일 받기 |

## 핵심 시나리오

### S1. 비서 만들기 (오너)
1. 가입 → 온보딩 위저드: 내 이름·직업·소개(프로필), 비서 이름·말투(페르소나 프리셋), 모델 선택.
2. 비서가 생성되고 오너 채팅에서 바로 대화. 비서가 "저에 대해 더 알려주세요" 식으로 오너 인터뷰 →
   답변이 **프로필/사실 원장/메모리**에 저장된다.
3. 파일 업로드(이력서·포트폴리오·회사 소개·FAQ) → 지식 색인.
4. 인맥 추가(수동/구글 연락처 가져오기) → 그래프.
5. 구글 연동 → 최근 메일 요약·일정을 비서가 참조.

### S2. 공개하기 (오너)
1. [공개 링크 만들기] → `mfsg.hrletsgo.me/{code}` 생성. 코드는 자동(8자) 또는 커스텀 핸들.
2. 공개 경계 정책 선택: **공개할 것**(직업·소개·공개 링크·FAQ), **절대 비공개**(연락처·주소·재정·
   특정 인맥), **문의 시 대응**(미팅 요청 → 메시지 남기기).
3. 링크/QR 공유. 명함·이메일 서명·SNS 프로필에 붙인다.

### S3. 대화하기 (방문자, 모바일)
1. 링크 열면 즉시 채팅(가입 없음). 비서 인사 + 추천 질문 칩.
2. "OO님 다음주 미팅 가능하세요?" → 비서가 공개 캘린더 가용성 범위 안에서 답하고,
   미팅 요청을 남기면 오너에게 알림.
3. 음성 입력(STT) / 음성 답변(TTS) 선택 가능.
4. 대화는 방문자 브라우저에 이어지고(익명 토큰), 방문자가 이름/이메일을 남기면 인박스에 식별.

### S4. 되돌아보기 (오너)
1. 인박스: 방문자 대화 목록·요약·남긴 메시지·미팅 요청.
2. 알림: 새 대화/메시지/요청 → 이메일·텔레그램·슬랙·웹훅. 일간 다이제스트.
3. 비서가 몰라서 못 답한 질문 목록 → "이 질문에 답을 가르쳐주세요" → 지식 보강 루프.

### S5. 운영하기 (관리자)
1. 최초 가입 → 관리자. 프로바이더 키(Claude Code 로그인·Anthropic·OpenAI·Gemini) 등록.
2. 모델 카탈로그에서 노출할 모델·크레딧 단가 설정, 플랜(free/pro) 정의.
3. 사용자·크레딧·사용량·에러 모니터링. 가입 정책(개방/초대).

## 제품 원칙

1. **비서다움**: 정보 나열이 아니라 대리 응대. 모르면 지어내지 않고 "남겨두면 전달한다".
2. **경계 존중**: 오너가 정한 공개 경계를 프롬프트+도구 스코프+후처리 3중으로 지킨다.
3. **가벼운 시작**: 가입 3분 안에 비서가 뜬다. 고급 설정은 뒤에.
4. **모바일 우선**: 방문자 UI 는 한 손 조작. 데스크톱 오너 콘솔은 넓게.
5. **투명한 비용**: 대화마다 크레딧 표시, 소진 전 경고, 소진 시 정중한 오프라인 안내.

## 비목표(v1 에서 하지 않음)

- 다중 에이전트 협업/위임, 코드 실행 샌드박스, 아바타/음성 클로닝, 데스크톱 앱,
  자체 결제 게이트웨이 운영(결제는 어댑터 뒤, v1 은 관리자 수동 충전 + Stripe 준비만),
  팀/조직 계정(계정=개인), 멀티 리전.

## 성공 기준 (M8 완료 시)

- 오너가 가입→비서 생성→공개 링크→방문자 대화→알림 수신까지 **운영 서버에서 E2E 통과**.
- 공개 채팅 Lighthouse 모바일 성능 ≥ 90, PWA 설치 가능, iOS Safari 키보드/세이프에어리어 정상.
- 크레딧 원장이 모든 턴의 토큰 사용량과 1:1 대응(누락 0).
- 관리자만 인프라 설정 접근 가능(권한 테스트 통과).
