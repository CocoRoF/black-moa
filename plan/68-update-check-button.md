# plan/68 — [업데이트 확인]: 앱을 다시 켜지 않고 새 판을 안다

## 0. 요청 (2026-09-28)

새 버전이 나와도 앱을 껐다 켜야 알게 된다. 설정 [정보] 에 [업데이트 확인] 을 두어 업데이트 상태를 새로 고친다.

## 1. 그때의 사정 (0.8.4~0.8.6)

- 새 판 확인은 로그인할 때·본창에 돌아올 때·잠에서 깰 때였고, **여섯 시간에 한 번까지**만 물었다. 켜 둔 채로는
  사실상 다시 켜야 알았다.
- [정보] 의 단추는 [다운로드 센터](브라우저로 열기) 하나였다. 이름이 `checkUpdate` 였지만 확인하지 않았다.

## 2. 한 것 (0.8.7)

- [정보]: [업데이트 확인] + ([업데이트] 또는 [다운로드 센터]).
  - 누르면 "새 버전이 있는지 확인하고 있어요."(너무 빨리 끝나 눌렸는지 모르지 않게 0.6초는 보인다) → 최신이면
    "버전 x · 최신이에요 (방금 확인했어요)", 새 판이면 "새 버전(y)이 나왔어요." 와 [업데이트].
  - 묻지 못하면 "확인하지 못했어요. 인터넷 연결을 확인해 주세요." 지난 업데이트 실패 문장은 새로 물은 결과로 바뀐다.
  - "몇 분 전에 확인했어요" 는 30초마다 다시 그려 멈춰 있지 않다.
- 저절로 묻기: 본창에 돌아올 때·잠에서 깰 때·**한 시간마다**, 하한 30분(여섯 시간에서 줄임).
- 트레이에도 [업데이트 확인](설정을 열고 묻는다).
- 계약: `shell.checkUpdate()` = 지금 묻기, `shell.openDownloads()` = 다운로드 센터. `UpdateInfo` 에 `checking`·
  `checkedAt`·`checkError`.

## 3. 확인

- `test/update.mjs` 5건: [업데이트 확인] 이 있다, 누르면 확인 중, 최신이면 "방금 확인했어요", 앱의 판을 낮추고(새
  판이 나온 것과 같다) 다시 누르면 **다시 켜지 않아도** [업데이트] 가 나온다, 상태에 남는다.
- 단위 29건, `test/shell.mjs` 18건.

## 4. 알아 둘 것

- 0.8.6 이하는 여섯 시간 하한이 그대로라, 0.8.7 은 켜 둔 앱이 다음에 본창으로 돌아올 때(여섯 시간 뒤)나 다시 켤 때
  안다. 0.8.7 부터는 [업데이트 확인] 한 번이면 된다.
