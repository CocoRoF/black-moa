# plan/57 — [내 정보]는 나와 내 프로필, 비서 [지식] 탭은 외부인에게 무엇을 쓰나

상태: **확정 (2026-09-25)** · 사용자 검토 반영

## 0. 철학 (사용자 말씀)

1. **[내 정보]는 원천이다.** 정보·스케줄·메일·피드·지식·파일·인맥은 내 것이고, 비서는 연결해서 쓴다.
2. **[내 정보]에서 공개 범위를 정하는 곳은 [정보]뿐이다.** [정보]는 내 프로필 페이지에 그대로 보이므로
   공개 범위(모두 공개 · 인맥에게만 · 비공개) = "내 프로필에서 누구에게 보이나". 비서와 무관하다.
3. **무엇을 외부인에게 쓸지는 비서의 [지식] 탭에서 정한다.** [정보]는 "프로필에 보이는 것을 쓸지",
   지식·파일·인맥·스케줄·기억·웹 검색은 "쓸지, 누구에게, 무엇을".
4. **나와의 대화에서는 비서의 모든 기능이 켜져 있다.** [지식] 탭에는 나와의 대화 칸이 없다.
5. **바깥 서비스는 [내 정보]의 한 곳을 거친다.** Google 캘린더 → 스케줄, Google 연락처 → 인맥,
   Google 메일 → **[내 정보 → 메일] (신설)** → 비서. SMTP·IMAP 같은 다른 메일은 나중에 같은 자리에 붙는다.
6. **중복되거나 불필요해진 것은 걷어낸다.**

외부인에게 나가는 것 = (정보라면 프로필 공개 범위) ∩ (그 비서의 [지식] 탭 설정). 나와의 대화는 전부.

- 메일: `services/mail.py` — 메일함 목록·검색·읽기·가져오기·보낸 메일. 공급자 등록표(지금은 google; imap/smtp 자리). 도구 email_search/email_read 는 이 서비스만 부른다(주인 대화 전용, 메일함이 연결돼 있을 때).
  주인 대화의 "다가오는 일정"은 스케줄에서, "안 읽은 메일"은 메일에서.
