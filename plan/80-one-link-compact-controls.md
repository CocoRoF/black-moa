# plan/80 — 비서 하나에 공개 링크 하나, 컨트롤은 40px 까지

## 0. 지시 (2026-09-30)

- 홈 비서 카드의 공개 링크 칸이 링크가 있을 때와 없을 때 크기가 달랐다.
- 공개 링크는 비서 1개 = 링크 1개. 여러 개가 되지 않게.
- 홈의 "비서 ———— 전체보기" 줄을 없애고, [비서와 대화] 왼쪽에 [비서 관리].
- 버튼 44px, 탭형 토글 바탕 44/안 36 이던 것을 공통 부품에서 더 작게. 위아래 40px 이 최대.

## 1. 한 것

### 공개 링크 하나
- DB: `uq_share_links_one_live_per_agent` — share_links(agent_id) 유일, `status <> 'revoked'` 인 것만(0084).
  옮기기 전에 둘 이상 살아 있던 비서는 가장 오래된 하나만 남기고 거둔다(운영에는 없었다).
- `services.agents.create_link`: 주소(handle) 검사 → 이미 살아 있는 링크가 있으면 409 `link_exists` → 플랜 한도.
- `PATCH /api/links/{id}`: 거둔 링크를 되살려 둘이 되는 길도 409 `link_exists`.
- 화면 `AgentLinks`: 머리의 [새 링크] 없음. 링크가 없을 때만 [공개 링크 만들기]. 카드는 한 장(max-w-2xl).
  설명 문구는 "비서마다 공개 링크는 하나예요". 거두면 새로 만들 수 있다고 알린다.

### 홈
- 머리: [비서 관리](/app/agents, outline) · [비서와 대화](accent). 비서 칸 위의 제목·전체보기 줄 제거.
- 카드의 링크 칸은 있든 없든 `h-9` 한 줄. 없으면 점선 테두리에 [공개 링크 만들기].

### 크기 (공통 부품이 정본)
| 부품 | 높이 |
|---|---|
| Button sm / md / lg | 32 / 36 / 40 |
| Button icon-sm / icon | 32 / 36 |
| Input · Selector · DatePicker(rcal) | 40 |
| Segmented (바탕 / 안) | 36 / 30, sm 은 안 26 |
| Tabs | 36 |

- 부품을 거치지 않고 h-11·h-12 로 박혀 있던 것(SSO 버튼, 채용, 회사 검색, 인증, 프로필, 사람 페이지, 태그 입력,
  분류 고르기, 사진 자르기·보기, 무대 상단 버튼 …)을 같은 눈금으로.
- 44px 로 남은 것은 버튼이 아니라 목록 행·설정 행(Switch 행, 하단 탭 막대 h-14, 회사 검색 첫 화면의 큰 검색창).
