# 정보 활용 심층 검토 리포트 — 2026-09-08

> "인맥에 추가된 것들이 제대로 답변에서 나오는지도 모르겠어. 정확하게 로직을 검토해보자."

비서가 **실제로** 어떤 정보를 쓸 수 있는지 실증으로 확인하고, 못 쓰는 것을 고친 기록.
코드를 읽고 추론한 게 아니라, 프로드에서 진짜 대화 턴을 돌려 답변 텍스트를 검사했다.

## 1. 계획

정보가 답변에 도달하는 경로는 5 갈래다 — 프로필(시스템 프롬프트), 지식(검색 도구),
인맥(그래프 도구), 가용성/연락규칙(프롬프트), 기억(메모리 스토어). 각각이
**오너 / 방문자** 두 청중에서 서로 다르게 열려야 한다(공개/비공개).
그래서 축은 `정보 종류 × 청중 × 공개여부` 이고, 검사는 "그 정보가 없으면 절대 답할 수
없는 질문"을 던져 값이 나오는지(공개) / 안 나오는지(비공개)를 본다.

## 2. 하네스

`tools/context_matrix.py` — 격리된 테넌트(자체 사용자·비서·공개 링크)를 만들고
**실제 API·실제 파이프라인·실제 모델**로 SSE 턴을 돌린다. 모킹 없음.

```
python tools/context_matrix.py --admin-pass '…'      # 끝나면 테넌트 삭제
```

심는 데이터: 프로필(공개 항목 + 비공개 전화·매출), 지식 문서 2건(공개 1/비공개 1),
FAQ 2건(공개 1/비공개 1), 인맥 노드 3개(공개 2/비공개 1) + 관계 1개, 가용 시간, 연락 규칙.
25 케이스에 프롬프트 인젝션 1건 포함.

## 4. 고친 결함 5건

### 4.1 업로드한 문서가 전부 색인 실패 (치명)
`embedding_key_missing`. 이 배포에는 임베딩 키가 없어 **모든 문서가 `failed`**,
즉 지식베이스가 사실상 비어 있었다. 검색은 원래 3-레그(벡터 ∪ tsvector ∪ 트라이그램)라
벡터 없이도 동작한다. 이제 벡터 없이 색인해 `ready` 로 두고,
`GET /api/knowledge/documents` 가 `semantic_search:false` 를 알리며 화면이
"지금은 키워드 검색만" 이라고 말한다. 키를 넣고 재색인하면 의미 검색이 켜진다.

### 4.2 공개 FAQ 가 한 번도 매칭되지 않음
임베딩이 없을 때 폴백이 `question ILIKE '%질문 전체%'` 였다. 방문자가 저장된 문장과
글자까지 똑같이 묻지 않는 한 절대 안 걸린다. 질문의 내용어가 질문·답변에 몇 개 나오는지로
점수를 매기고, 한국어 조사를 떼어 `결제사를`/`결제사가` 를 같은 어간으로 본다.
키워드 근거는 의미 매칭보다 약하므로 FAQ 임계값 아래 점수로 돌려준다.

### 4.3 "누가 메시지 남겼어?" 를 기억에서 지어냄
`leave_message` 는 정상 동작해 인박스 행을 만들었다. 그러나 `inbox_list` 는 **숨은 도구**라
CLI 가 광고하지 않는데, 새로 쓴 기본 프롬프트는 그것을 바로 부를 수 있는 것처럼 적어 두고
"숨은 도구는 ToolSearch 로 먼저 찾는다"는 문장을 빠뜨렸다. 모델은 포기하고 메모리를 뒤졌다.
`inbox_list` 를 광고 도구로 올리고, 남은 숨은 도구에는 `(search first)` 표시를 되살렸다.

### 4.4 그래프↔제안 탭 왕복 불가 (최초 신고 건)
스크롤 컨테이너의 자동 최소 크기는 0이다. 콘텐츠가 넘치는 flex 컬럼(인맥 페이지)에서
탭 스트립만 줄어들 수 있었고, **1px 테두리로 찌그러진 채 44px 버튼이 아래 목록 밑으로
깔려** 클릭이 가로채였다. 모든 탭 스트립에 `shrink-0`. Playwright 왕복 검증 통과.

### 4.5 크레딧 402 가 "잔액 부족"으로 보임
매트릭스가 402로 중단됐는데 잔액은 충분했다. 실제 원인은 플랜의 **하루 한도**(Free=100).
`daily_cap_reached` 에 클라이언트 문구가 없어 일반 오류로 떨어지고 있었다.
문구를 추가하고, 크레딧 화면에 **오늘 사용 / 하루 한도**를 표시한다.

### 4.6 인맥이 비공개인 걸 오너가 알 수 없음 (신고의 진짜 원인)
방문자가 손성준을 물었을 때 비서가 "찾을 수 없다"고 한 것은 **정상 동작**이었다 —
그 노드는 비공개이고, 대화에서 파생된 노드는 기본 비공개다. 다만 화면 어디에도 그 사실이
없어 버그로 보였다. 목록에 공개 배지를 넣고, 전부 비공개일 때는
"비공개 인맥은 방문자와의 대화에서 비서가 언급하지 않습니다 — 소개해도 되는 사람은
[공개]로 바꿔주세요" 라고 명시한다.

## 5. 운영자 판단이 필요한 것 2가지

1. **하루 크레딧 한도** — Free 플랜은 100/일. 잔액을 20만 넣어도 하루 100을 넘으면 멈춘다
   (실측 턴당 평균 7.1 크레딧 ≈ 하루 14턴). [관리자 → 플랜]에서 `daily_credit_cap` 조정.
2. **임베딩 키** — 지금은 키워드 검색만 동작. 문서가 늘면 의미 검색이 체감 차이를 만든다.
   [관리자 → 프로바이더]에 키를 넣고 [지식]에서 재색인.
3. (선택) 오너 본인의 인맥(손성준·Plateer)은 여전히 비공개다. 방문자에게 소개해도 되는
   사람만 [공개]로 바꾸면 방문자 대화에서도 언급된다.
